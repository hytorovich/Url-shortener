# Сервис коротких ссылок

Консольное приложение на Java 17. Сокращает ссылки, считает переходы, блокирует ссылку после исчерпания лимита и удаляет её по истечении срока жизни. Пользователь определяется по UUID.

## Запуск

Нужны JDK 17+ и Maven.
Внешние библиотеки (JUnit 5, Checkstyle) Maven скачивает сам при сборке, отдельно ничего устанавливать не нужно.

```bash
mvn verify
java -jar target/url-shortener.jar
```

## Команды

```text
create <url> [лимит]       создать короткую ссылку
sh.rt/<код>                перейти по ссылке
list                       мои ссылки
edit <код> limit <число>   изменить лимит
delete <код>               удалить ссылку
login <uuid> / logout      сменить пользователя
whoami                     показать UUID
help                       список команд
exit                       выход
```

Пример:

```text
> create https://www.baeldung.com/java-9-http-client 2
Ваш UUID: 478229a9-153a-45b9-ab8d-03dda1255c64
Короткая ссылка: sh.rt/HQyj6e
> sh.rt/HQyj6e
Переход 1 из 2: https://www.baeldung.com/java-9-http-client
```

## Настройки

Файл `src/main/resources/application.properties`: срок жизни ссылки, лимит по умолчанию, максимальный лимит, длина кода, домен и интервал очистки.

## Архитектура

- `core` - логика: `Link`, `LinkService`, фоновая очистка `ExpiredLinkCleaner`
- `config` - чтение настроек
- `cli` - консольные команды
- `Main` - создание объектов и запуск

Основные решения:

- код ссылки случайный, поэтому у разных пользователей ссылки на один адрес разные;
- проверка лимита и подсчёт перехода выполняются атомарно через `ConcurrentHashMap.computeIfPresent`;
- истёкшие ссылки удаляет фоновый поток, срок проверяется и при переходе;
- изменять и удалять ссылку может только владелец;
- данные хранятся в памяти.

## Тестирование

```bash
mvn test
```

34 теста на JUnit 5: создание и уникальность ссылок, лимит переходов (включая 100 одновременных переходов), удаление по сроку жизни, уведомления, права владельца, консольные сценарии и настройки.
